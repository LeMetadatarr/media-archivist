A collection is a named saved filter — "Blender open movies" could be source=='youtube' and grep=='blender'. It stays live: it always reflects the current library, and its /collections/<name>/m3u URL is a stable playlist Jellyfin/Kodi/VLC can subscribe to directly.

Filter syntax

Fields: title, source, duration, has_stream, explicit, artist, album, published.

Operators: == != > >= < <= and or.
